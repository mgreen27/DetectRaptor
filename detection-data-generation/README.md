# Detection data generation

Use these scripts on a disposable Windows lab VM to create fixtures for a Velociraptor collection. Each folder uses the filename of its detection artifact and documents how to generate, collect, and remove its fixtures.

| Detection artifact | Platform | Generation and cleanup |
|---|---|---|
| [ChromiumExtensionPersistence](../vql/ChromiumExtensionPersistence.yaml) | Windows, Chrome or Edge | [Chromium lab instructions](ChromiumExtensionPersistence/README.md) |
